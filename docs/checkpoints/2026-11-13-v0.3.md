## Goal and results

v0.2 established a working JSON timeline but visibly primitive geometric puppets and environments. v0.3 concentrates on a more expressive paper-cut illustration style **without discarding the v0.2 engine**. Implemented:

1. `illustration.py`: a reusable layered character with IK-driven anatomy, shaped coat/clothing seams, hair strands, facial states, eyes, mouth and gait.
2. `sprite_rig.py`: artist-authored transparent PNG body parts attached to named bones, sorted by `z`, mapped using declared `pivot` coordinates, scaled and rotated around their joints.
3. `cinematic.py`: a deterministic, original `moonlit_atelier` environment with bookshelves, large arched window, outdoor moon, floor perspective, depth branches, moving particles, lighting, vignette, title and cinematic subtitles.
4. Improved `timeline.py`: `pickup.hand_to` and placement-directed IK blending, so hands move toward the prop rather than having the prop float entirely to an unrelated fixed grip.
5. Render integration: `cinematic_storybook` style, `lantern` light-emitting prop, cinematic character selection, scene-configurable `supersample:1..3` for Lanczos antialiasing, safety-bounded offscreen resolution.
6. `model.py` + `assets.py`: v0.3 contract, strict artistic/sprite input validation, local asset checks and manifest SHA-256 tracking.

## Acceptance

`examples/lantern_keeper_v03.json` is the 10-second single-scene cinematic test (default 960×540, 24fps). The actual pipeline renders H.264 from deterministic Pillow frames, and CI produces full-motion preview MP4, 960×540 snapshots, and decoded QA PNGs. The character approaches a lantern, performs an IK reach and pickup, carries it, then places it down; title/captions and illumination are layered over continuous motion.

`tests/test_visual_v03.py` verifies v0.3/legacy compatibility, new visuals, static-frame determinism, prop attachment, invalid art/quality inputs, and supersampling. `tests/test_sprite_rig.py` builds actual transparent PNG parts in a temp directory and verifies skeletal rotation, repeatability, manifest and path validation. Unit tests, integration checks, and real FFmpeg rendering all run under GitHub Actions Ubuntu.

## Actual visual review and remaining work

Frame inspection found and led to repairs of exaggerated elbow folding, knee crossing, and disconnected grasp targets. Improvements were committed and verified through rendered film QA, not merely source inspection. **The illustrated puppet is still stylized** and does not have the aesthetic versatility of a hand-illustrated studio rig. The new importable PNG sprite pipeline is therefore central: high-quality artwork can be substituted without rewriting motion logic.

Remaining engineering tasks:
- Authoring a professional artist-made sprite catalog with expression/hair/hand variants.
- Weight-skinned deformable meshes, articulated hands/fingers and convincing hip/torso motion.
- Rig retargeting and bone-label conventions between imported characters.
- Film-level visual regression tests with stable review thumbnails and optional perceptual checks.
- Advanced staging: shot-based camera plans, occlusions, shadow casting, character-object contact solving and lighting masks.
- Phoneme timing from real WAV audio, and integration tests with AetherMotion, ClaudeCreate and AetherRendering.

Do not claim these absent features exist. v0.3 adds an improved visual baseline **and an asset-upgrade path**, not a professional animation studio.
